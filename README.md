## 🎯 Overview

**Hina Textiles** is a professional business website built with modern web technologies to showcase industrial textile products and services. The site features a premium UI/UX with **fluid animations**, **responsive design**, and a **conversion-focused layout** to connect clients with the company.

## 🎬 Animations & Interactions

The site makes extensive use of **Framer Motion** for a polished, premium feel:

```
┌────────────────────────────────────┬───────────────────────────────────┐
│         ANIMATION TYPE             │         WHERE IT'S USED           │
├────────────────────────────────────┼───────────────────────────────────┤
│  ↕️  Fade + Slide Up               │  Hero text, section headings      │
│  ↔️  Fade + Slide Horizontal       │  About image/text split layouts   │
│  🔄 Scale + Fade                   │  Stats cards, floating badges     │
│  👁️ Scroll-triggered (whileInView) │  Features, products, timeline     │
│  🔃 Infinite Loop (y: [0,8,0])     │  Scroll indicator dot             │
│  🏷️ Layout Animation (layoutId)    │  Active nav indicator underline   │
│  🔀 AnimatePresence                │  Mobile menu open/close           │
│  🎡 Rotate Toggle                  │  Hamburger ↔ Close icon morph     │
│  📈 Staggered Entrance             │  Product cards, milestone steps   │
│  💫 Hover Scale                    │  Feature icons, value cards       │
│  💚 Ping Animation (CSS)           │  WhatsApp button pulse ring       │
│  🔼 Hover Translate-Y              │  CTA buttons, social icons        │
└────────────────────────────────────┴───────────────────────────────────┘
```

## 🚀 Getting Started

### Prerequisites

- **Node.js** `v18+` — [Download](https://nodejs.org/)
- **npm** `v9+` (ships with Node.js)

### Installation

```bash
# 1️⃣ Clone the repository
git clone https://github.com/itsfraz/h-textile.git

# 2️⃣ Navigate to the project
cd h-textile

# 3️⃣ Install dependencies
npm install

# 4️⃣ Start the development server
npm run dev
```

The app will be available at **`http://localhost:5173`** 🎉

### Available Scripts

| Command | Description |
|:--------|:------------|
| `npm run dev` | 🔥 Start Vite dev server with HMR |
| `npm run build` | 📦 Build production bundle to `dist/` |
| `npm run preview` | 👀 Preview production build locally |
| `npm run lint` | 🔍 Run ESLint code quality checks |
